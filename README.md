# Monitor Sleep v0.05.00

Windows x64용 Rust 모니터 제어 프로그램입니다. 총 2대 이상(메인 1대 + 서브 1대 이상)의 독립 확장 화면을 정상 구성으로 처리합니다.

[최신 릴리즈 다운로드](https://github.com/ANSungnam/monitor_sleep-release/releases/tag/v0.05.00)

## 설치

1. ZIP을 D:\에 풀어 `D:\monitor_sleep_v0.05.00\monitor_sleep.exe`가 되게 합니다.
2. 함께 제공하는 SHA256SUMS.txt로 다운로드 파일의 해시를 확인합니다.
3. monitor_sleep.exe를 실행하고 Windows 관리자 권한 요청을 승인합니다. 기존 서비스가 있으면 새 버전으로 교체됩니다.
4. 배포 설정은 일시정지, 유휴 시간 5분입니다. 자동 제어를 사용하려면 트레이에서 재개합니다.

이 버전의 설치·설정 위치는 D:\monitor_sleep_v0.05.00으로 고정되어 있으며 D: 드라이브가 필요합니다. v0.03.04 공개판의 임의 폴더 설치 방식과 다릅니다.

## 변경 내용

- 2대 구성에서 세 번째 모니터를 반복 검색·강제 복구하는 동작을 수정한 0.04.00 로직을 유지합니다.
- 자동 시작·복구·깨우기에서 Windows의 기존 화면 배치를 유지합니다.
- 실행 파일과 문서를 정리하고 버전 및 설치 경로를 0.05.00으로 변경했습니다.

## 검증 범위

비공개 원본 검증 기록에는 0.05.00의 fmt, 20개 테스트 통과(대화형 Explorer 테스트 1개 제외), 오프라인 release 빌드와 버전·화면 구성 확인이 기록되어 있습니다. 이번 GitHub 업로드에서는 배포 파일의 SHA-256을 대조했습니다.

1시간 관찰은 기반 0.04.00을 일시정지 상태에서 수행한 기록이며, 0.05.00의 별도 1시간 동작 시험은 아닙니다. 모든 모니터의 밝기 제어 또는 Windows 10 실기기 호환을 보증하지 않습니다. 밝기 제어는 모니터와 연결 경로의 지원에 따라 달라집니다.

상태 확인: `monitor_sleep.exe --status`
제거: `monitor_sleep.exe --uninstall`

Rust 소스와 오프라인 빌드 의존성은 기존 비공개 소스 저장소에서 관리합니다. 공개 Release의 ZIP은 실행용 배포본입니다.
