# Monitor Sleep v0.06.00

Windows 10 및 Windows 11 x64용 관리자 권한 모니터 제어 프로그램입니다.

## 설치 및 자동 시작

1. 패키지를 D:\에 풀어 `D:\monitor_sleep_v0.06.00` 폴더를 만듭니다.
2. `monitor_sleep.exe`를 실행하고 최초 Windows 관리자 권한 요청을 승인합니다.
3. 프로그램이 LocalSystem 자동 시작 서비스 `monitor_sleep`와 현재 설치 계정의 관리자 권한 예약 작업 `MonitorSleepTray`를 등록하고 트레이 시작을 확인합니다.

서비스는 부팅 시 실행되고, 트레이는 설치 계정이 로그인한 뒤 10초 후 시작됩니다. 설치 직후에는 트레이를 즉시 실행합니다. 서비스와 트레이의 실행 경로는 모두 `D:\monitor_sleep_v0.06.00\monitor_sleep.exe`입니다. C:로 실행 파일을 복사하지 않습니다. Windows 자체 서비스/작업 등록 데이터는 운영체제가 관리합니다.

다른 PC에서도 실행 시 해당 PC의 계정 SID를 읽어 예약 작업을 생성합니다. 계정 이름, 암호 또는 이 PC의 SID를 코드에 고정하지 않았습니다. 최초 등록은 관리자 계정에서 해야 하며, 권한 승인을 취소하면 일반 권한으로 대신 실행하지 않습니다. D:는 부팅 때 접근 가능한 로컬 고정 드라이브여야 합니다. D:가 없으면 명확한 오류를 표시합니다. 작업 스케줄러 서비스가 사용 가능해야 합니다. BitLocker 등으로 D:가 잠겨 있으면 부팅 전에 잠금이 해제되어야 합니다.

실행 파일의 매니페스트와 코드 모두 관리자 권한을 요구합니다. 설치 폴더는 SYSTEM/Administrators 쓰기, 일반 사용자 읽기·실행 권한으로 보호합니다. 코드 수정과 업데이트에는 관리자 권한이 필요합니다. 실행 파일을 옮기거나 지우면 등록된 경로를 사용할 수 없으므로 이 폴더를 유지하세요.

Windows 기본 API 및 schtasks.exe만 사용합니다. Visual C++ 런타임은 정적 링크하므로 별도 Python, Node.js, PowerShell 또는 VC++ 재배포 패키지를 설치할 필요가 없습니다. 대상은 x64입니다. Windows 10 현재 PC에서 실행 검증하며 Windows 11 실기기 검증은 별도입니다.

## 트레이 및 설정

트레이에서 일시정지·재개와 유휴 시간을 바꿀 수 있습니다. 이번 패키지는 현재 설정 `paused=false`, `idle_seconds=3600`(제어 켜짐, 60분)을 보존했습니다. 아이콘이 숨겨진 경우 Windows 알림 영역의 펼침 메뉴에서 확인하세요. Explorer 재시작 시 아이콘을 자동 복구하고 한 사용자 세션에서 중복 에이전트가 실행되지 않도록 합니다.

최소 두 대의 독립 확장 모니터를 사용하며, 기존 자동 모니터 제어 동작을 유지합니다. 특정 3대 배치를 자동으로 강제하지 않습니다. 설정·로그·복구 파일은 모두 D: 설치 폴더에 저장됩니다. `끝내기`는 기존 동작처럼 서비스와 자동 시작 등록을 제거합니다. 다시 실행하면 재등록됩니다.

## 명령

- 기본 실행: 서비스와 로그인 예약 작업 설치/복구 및 트레이 시작 확인
- `--install`: 서비스와 로그인 예약 작업 설치. 현재 세션의 트레이를 즉시 실행하지 않음
- `--update-service`: 별도로 빌드한 실행 파일로 서비스/예약 작업 갱신 후 트레이 시작 확인
- `--startup-status`: 관리자 권한 및 예약 작업 상태
- `--verify-tray`: 트레이 등록 준비 신호 확인
- `--status`, `--display-status`, `--version`: 상태 조회
- `--uninstall`: 서비스와 로그인 예약 작업 제거

## 검증 및 소스

Windows 10 Pro 22H2 x64에서 서비스·관리자 권한 예약 작업·트레이 아이콘의 실제 등록을 확인했습니다. 자동 테스트 24개 통과, Explorer 통합 테스트 1개 제외, fmt·clippy·release 빌드를 통과했습니다. Windows 11 실기기 및 실제 재부팅/재로그인 검증은 미실시입니다.
