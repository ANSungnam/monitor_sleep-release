## Monitor Sleep v0.06.00

- 실행 파일 매니페스트와 코드에서 관리자 권한을 확인합니다.
- 최초 실행 시 LocalSystem 자동 시작 서비스와 설치 계정의 관리자 권한 로그인 예약 작업을 등록합니다.
- 서비스는 부팅 시, 트레이는 해당 계정 로그인 10초 후 실행하도록 설정합니다. 설치 직후 트레이를 즉시 시작하고 중복 실행 및 Explorer 재시작 복구를 처리합니다.
- 실행 파일·설정·로그 경로는 `D:\monitor_sleep_v0.06.00`입니다. 다른 PC에서는 해당 설치 계정의 SID를 자동으로 사용합니다.
- Windows 10/11 x64 대상이며 VC++ 런타임을 정적 링크했습니다.

## 설치

설정이 포함된 **monitor_sleep_v0.06.00_windows_x64.zip**을 D:\에 풀고 `D:\monitor_sleep_v0.06.00\monitor_sleep.exe`를 실행하여 관리자 권한 요청을 승인하세요. D:는 부팅 시 접근 가능한 로컬 고정 드라이브여야 합니다. 기존 서비스가 있으면 새 버전으로 갱신합니다.

배포 설정은 **제어 켜짐, 유휴 시간 60분**입니다. 트레이에서 변경할 수 있습니다. `--status`로 상태를 확인하고 `--uninstall`로 서비스와 로그인 예약 작업을 제거할 수 있습니다.

단독 EXE는 ZIP과 동일한 빌드입니다. ZIP에는 실행 파일, 설정, 사용 설명, 의존성 라이선스가 포함되며 전체 소스는 기존 비공개 저장소에 보관합니다.

## 검증

- Windows 10 Pro 22H2 x64에서 LocalSystem 서비스, 관리자 에이전트 1개, 로그인 10초 지연 예약 작업, 실제 트레이 등록을 확인했습니다.
- 자동 테스트 24개 통과, 실패 0, Explorer 통합 테스트 1개 제외. fmt, clippy, release 빌드 및 내장 관리자 매니페스트 검증 통과.
- Windows 11 실기기 및 실제 재부팅/재로그인 검증은 미실시입니다.
- 다운로드 후 첨부 SHA256SUMS.txt와 `Get-FileHash <파일명> -Algorithm SHA256` 결과를 비교하세요.
